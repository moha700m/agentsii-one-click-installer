دليل استخدام Agentsii One-Click API Installer

ربط أي مزوّد API متوافق مع OpenAI Codex بضغطة واحدة — الإصدار 1.0.0

1. ما الذي يفعله البرنامج؟

تكتب ثلاثة أشياء فقط: اسم المزوّد ورابط الـ API والمفتاح، ثم تضغط ONE-CLICK CONNECT. يتولى البرنامج الباقي: يتحقق من الرابط والمفتاح، ويكتشف الموديلات من المزوّد نفسه، ويختبر كل موديل اختباراً حقيقياً، ثم يضيف الموديلات المتوافقة فقط إلى إعدادات Codex، ويحفظ المفتاح في Windows Credential Manager.

لا تحتاج إلى Terminal، ولا إلى تعديل config.toml يدوياً، ولا إلى كتابة أسماء الموديلات، ولا إلى رصيد OpenAI.

2. المتطلبات

  • Windows 10 أو Windows 11 (64-bit).
  • OpenAI Codex مثبّت: Codex CLI، أو تطبيق Codex Desktop الذي يقرأ الإعدادات من config.toml.
  • مزوّد يدعم OpenAI Responses API ويوفر قائمة موديلات /models.
  • لا تحتاج إلى تثبيت Python أو أي مكتبة.

3. أي ملف أستخدم؟

الملفمتى تستخدمه
AgentsiiSetup.exeمثبّت Windows. يثبّت البرنامج لحسابك فقط (بدون صلاحيات مدير)، ويضيف اختصاراً في قائمة ابدأ وهذا الدليل. الخيار الموصى به.
AgentsiiPortable.exeنسخة محمولة بملف واحد، تعمل مباشرة دون تثبيت (من فلاشة أو من مجلد التنزيلات).
AgentsiiInstaller.exeالملف التنفيذي للبرنامج بعد التثبيت (داخل مجلد البرنامج). موجود أيضاً في AgentsiiInstaller-app.zip.
تنبيه SmartScreen: الملفات غير موقّعة رقمياً بعد، لذا قد يظهر تحذير «Windows protected your PC» عند أول تشغيل. اضغط More info ثم Run anyway. لإزالة هذا التحذير نهائياً يجب توقيع الملفات بشهادة Code Signing.

4. خطوات الاستخدام

  1. افتح البرنامج.
  2. اكتب Provider Name — أي اسم تختاره، مثل My Gateway. يُستخدم كمعرّف المزوّد داخل Codex (مثلاً my-gateway).
  3. اكتب API Base URL — مثل https://api.example.com/v1. إذا نسيت /v1 سيجرّبه البرنامج تلقائياً، وإذا ألصقت رابطاً كاملاً مثل …/v1/chat/completions سيصححه.
  4. الصق API Key.
  5. اضغط ONE-CLICK CONNECT وراقب المراحل.

يمكنك التبديل بين العربية والإنجليزية من الزر أعلى النافذة.

5. المراحل الثماني

المرحلةما يحدث فعلياً
[1] Checking API URLيتحقق من صيغة الرابط ويتصل بالمزوّد مباشرة. يرفض http:// للخوادم البعيدة حتى لا يُرسل مفتاحك دون تشفير (مسموح فقط لـ localhost والشبكة المحلية).
[2] Verifying API Keyيطلب قائمة الموديلات بالمفتاح؛ إذا رفضه المزوّد (401/403) يتوقف فوراً.
[3] Discovering Modelsيقرأ كل الموديلات من /models ويستبعد غير المناسبة لوكيل برمجي (Embeddings، صوت، صور، Moderation...). لا يخترع أي اسم موديل.
[4] Checking Codex Compatibilityيكتشف دعم Responses API وChat Completions، ثم يرسل لكل موديل طلباً حقيقياً متدفقاً (Streaming) مع Function Tool كما يفعل Codex. يُضاف فقط الموديل الذي ينجح.
[5] Detecting Codex Installationيجد Codex CLI وCodex Desktop ومجلد الإعدادات، ويحترم CODEX_HOME إن وُجد (وإلا %USERPROFILE%\.codex).
[6] Configuring Providerينشئ نسخة احتياطية من config.toml أولاً، ثم يضيف المزوّد والموديلات ويضبط الموديل الافتراضي، مع الحفاظ على كل إعداداتك وتعليقاتك السابقة.
[7] Securing API Credentialsيحفظ المفتاح في Windows Credential Manager فقط.
[8] Final Verificationيعيد قراءة الإعدادات ويتأكد أن Codex سيتمكن من قراءة المفتاح فعلاً.
إذا فشلت أي مرحلة بعد بدء التعديل، يُعيد البرنامج كل شيء كما كان: ملف الإعدادات، وملفات الـ Profiles، وبيانات الاعتماد. ولا تظهر رسالة SUCCESS! إلا إذا نجحت كل المراحل فعلاً.

5.1 المزوّدات التي تدعم Chat Completions فقط (الجسر المحلي)

إصدار Codex الحالي يتكلم Responses API فقط. إذا كان مزوّدك يدعم Chat Completions فقط، يفعّل البرنامج تلقائياً جسر Agentsii المحلي: خادم صغير على جهازك فقط (127.0.0.1) يترجم طلبات Codex إلى Chat Completions ويعيد الردود بصيغة Codex، بما في ذلك الأدوات (Tools) والبث المباشر.

  • يعمل تلقائياً عند تشغيل Codex، ويتوقف وحده بعد ساعات من عدم الاستخدام. لا تحتاج لتشغيله يدوياً.
  • لا يُخزّن المفتاح؛ يمرّره فقط من Credential Manager إلى المزوّد.
  • يظهر في شاشة النجاح: طريقة الربط: عبر جسر Agentsii.
  • حدود: أدوات OpenAI المستضافة مثل البحث في الويب غير متاحة عبر الجسر.

6. بعد النجاح

  • OPEN CODEX: يفتح Codex Desktop إن وُجد، وإلا يفتح Codex CLI في نافذة جديدة. المزوّد الجديد أصبح هو الافتراضي.
  • ADD ANOTHER API: يعيدك إلى النموذج لإضافة مزوّد آخر.
  • Show models: يعرض الموديلات المضافة (★ = الافتراضي) والموديلات المستبعدة مع سبب الاستبعاد.

استخدام موديل آخر غير الافتراضي

لكل موديل متوافق يُنشأ Profile رسمي في Codex باسم agentsii-<provider>-<model>. مثال:

codex --profile agentsii-my-gateway-model-name

أو مرّر اسم الموديل مباشرة: codex -m model-name. الأسماء الدقيقة تظهر في «Show models».

7. ماذا يكتب البرنامج في إعدادات Codex؟

# %USERPROFILE%\.codex\config.toml  (أو CODEX_HOME)
model_provider = "my-gateway"
model = "best-compatible-model"

[model_providers.my-gateway]
name = "My Gateway"
base_url = "https://api.example.com/v1"
wire_api = "responses"

[model_providers.my-gateway.auth]
command = "C:\\Users\\you\\AppData\\Local\\Agentsii\\bin\\agentsii-auth.exe"
args = ["--provider", "my-gateway"]
timeout_ms = 20000
refresh_interval_ms = 0

هذه هي طريقة Codex الرسمية للمصادقة عبر أمر (command-backed auth): عندما يحتاج Codex المفتاح يشغّل agentsii-auth.exe الذي يقرأه من Credential Manager ويسلّمه لـ Codex مباشرة. المفتاح لا يُكتب في أي ملف ولا في متغيرات البيئة ولا في السجلات.

8. الأمان والخصوصية

  • المفتاح يُرسل فقط إلى المزوّد الذي كتبته، ولا يُرسل إلى Agentsii أو أي جهة أخرى.
  • يُحفظ في Windows Credential Manager باسم agentsii-codex:<provider> (لوحة التحكم ← Credential Manager ← Windows Credentials).
  • لا يُطبع المفتاح في السجل: %LOCALAPPDATA%\Agentsii\logs\agentsii.log.
  • نسخة احتياطية قبل أي تعديل في .codex\agentsii-backups\.
  • لا يستبدل مزوّداً موجوداً بنفس الاسم إلا بعد موافقتك.
  • لا يحتوي البرنامج على أي مفاتيح افتراضية.

9. حل المشكلات

الرسالةالمعنى والحل
رفض المزوّد هذا المفتاح (401/403)المفتاح خاطئ أو منتهٍ أو بلا صلاحية. انسخه من جديد من لوحة المزوّد.
المزوّد لا يوفّر قائمة موديلاتالمزوّد لا يدعم /models. البرنامج لن يخترع أسماء موديلات، لذا لا يمكن الإكمال تلقائياً.
المزوّد لا يدعم Responses API ولا Chat Completionsالمزوّد غير متوافق مع صيغة OpenAI، ولا يمكن ربطه بـ Codex.
لم ينجح أي موديل في اختبار التوافقافتح «Show models» لرؤية سبب كل موديل (رصيد غير كافٍ، Rate limit، عدم دعم Tools...).
لم يُعثر على Codexثبّت Codex أولاً، أو افتحه مرة واحدة حتى يُنشئ مجلد الإعدادات.
ملف config.toml غير قابل للقراءةملفك الحالي فيه خطأ صياغة، فلم يلمسه البرنامج. أصلحه أو استرجع نسخة احتياطية.
تحذير SmartScreenMore info ← Run anyway (الملفات غير موقّعة بعد).

للتفاصيل الكاملة افتح «Open log» من البرنامج.

10. التراجع والإزالة

  • استرجاع الإعدادات السابقة: انسخ آخر ملف من .codex\agentsii-backups\ فوق .codex\config.toml.
  • حذف المفتاح: Credential Manager ← Windows Credentials ← احذف agentsii-codex:<provider>.
  • إلغاء التثبيت: من «Apps & features». لا يحذف إلغاء التثبيت أداة agentsii-auth.exe عمداً حتى لا يتعطل Codex؛ احذف المزوّد من الإعدادات أولاً ثم احذف %LOCALAPPDATA%\Agentsii.
