Agentsii One-Click API Installer

Connect any OpenAI-Codex-compatible API provider in one click. The full guide is in Arabic (UserGuide-AR.html); this is the short version.

Use

  1. Open the app.
  2. Enter Provider Name, API Base URL and API Key.
  3. Click ONE-CLICK CONNECT.

What happens

URL and key are checked against the provider, models are read from /models (never invented), each candidate model gets a real streamed Responses API call with a function tool (what Codex needs; current Codex supports only wire_api = "responses"), Codex is detected (respecting CODEX_HOME), config.toml is backed up, the provider and default model are written, one Codex profile per compatible model is created, the key is stored in Windows Credential Manager and Codex reads it through the official command-backed auth ([model_providers.<id>.auth]). Any failure after changes started restores everything.

codex --profile agentsii-<provider>-<model>

Security

The key only goes to your provider and to Windows Credential Manager; it is never written to config files, environment variables or logs, and never sent to Agentsii. Existing providers are never replaced without your approval.

Files

Log: %LOCALAPPDATA%\Agentsii\logs\agentsii.log · Backups: .codex\agentsii-backups\ · Auth helper: %LOCALAPPDATA%\Agentsii\bin\agentsii-auth.exe

SmartScreen may warn because the files are not code-signed yet: More info → Run anyway.
